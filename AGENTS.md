# Agent instructions — {{VAULT_NAME}}

This vault's operating instructions live in **[CLAUDE.md](CLAUDE.md)**. They are tool-agnostic;
read that file whatever agent you are.

The one rule worth knowing before you touch anything:

> **The `obsidian-git` plugin owns `main`.** It auto-commits and pushes on a timer. Write notes
> freely — never hand-commit them. Configuration changes (`.obsidian/`, `scripts/`, `.gitea/`)
> ship like code: branch → PR.

**Finding anything:** start at [Landing.md](Landing.md), open the area's landing page, and follow
its links down to the page or SOP you need. Before adding a page, decide which landing page it
belongs under (see *How to add a page* in Landing.md).

The vault standard and the reasoning behind each rule: **[docs/VAULT-STANDARD.md](docs/VAULT-STANDARD.md)**.
